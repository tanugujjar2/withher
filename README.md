# pcos_caregiver_companion

Soft, supportive Flutter mobile app for **partners and family members** who want to understand and support loved ones living with **PCOS/PCOD**.

This app is **not** for the patient directly. It’s designed to help caregivers build empathy, choose kinder words, and show up consistently.

## What’s inside (MVP)

- **PCOS vs PCOD education** (simple, low-jargon comparison)
- **Normal vs PCOS/PCOD “hard day”** hormone + mood framing
- **Daily empathy simulator** (emotional + physical “possible states”)
- **Support suggestion engine** (pick symptoms → get practical, gentle support ideas)
- **“What Not To Say”** guidance (with healthier replacements)
- **Hormone education mini-cards** (tiny explanations + support tips)
- **Mental health awareness** (validation-forward framing)
- **Relationship support tracker** (log supportive actions; saved on-device)

## Run it

```bash
cd pcos_caregiver_companion
flutter pub get
flutter run
```

## Windows note (important)

On Windows, `flutter pub get` can fail with:

> Building with plugins requires symlink support.

This project uses plugins (e.g. `shared_preferences`) for on-device storage, so **Developer Mode must be enabled**.

- Open Windows Developer settings by running:

```powershell
start ms-settings:developers
```

- Turn on **Developer Mode**, then re-run:

```bash
flutter pub get
```

## Design intent

- Pastel, emotionally safe, “caring companion” feel
- Minimal medical jargon
- Focus on empathy, communication, and practical support
